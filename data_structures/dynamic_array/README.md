# Dynamic array

## Description

A dynamic array is an array that can grow or shrink in size while automatically reallocating the necessary memmory. It also keeps its ability for fast random access to elements.

## Operations

- Append: O(1)
- Pop: O(1)
- Insert: O(N)
- Get: O(1)

## Pros

- Automatically grows or shrinks as needed
- Fast index access

## Cons

- Risk of memmory leak
- Higher complexity than a static array
- Some operations can be costly in terms of memmory
